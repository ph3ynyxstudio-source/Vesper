VISUAL_REFERENCE

Objectif

Permettre de retrouver rapidement les éléments visuels importants du projet.

Chaque entrée doit contenir :

- le fichier ;
- la ligne ;
- le rôle ;
- l'impact visuel ;
- le lien direct.
